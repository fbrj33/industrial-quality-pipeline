# Industrial Quality Streaming Pipeline

An end-to-end Data Engineering project that simulates semiconductor production events and detects manufacturing quality anomalies in a streaming pipeline.

## Objectives

- Ingest historical production data in batch and streaming modes.
- Use Apache Kafka for event ingestion.
- Process real-time measurements with Spark Structured Streaming.
- Store production measurements and anomaly results in PostgreSQL.
- Build analytical data models and quality tests with dbt Core.
- Visualize manufacturing quality indicators in Power BI.
- Measure pipeline throughput, latency, and reliability.

## Technology Stack

Python, Apache Kafka, Apache Spark, PostgreSQL, dbt Core, Docker Compose, Power BI.
